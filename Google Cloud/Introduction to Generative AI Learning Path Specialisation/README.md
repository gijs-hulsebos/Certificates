### ☁️ Google Cloud: Introduction to Generative AI Learning Path
This specialized learning path provides a deep dive into the fundamental technologies of Generative AI. It covers the transition from traditional Machine Learning to Large Language Models (LLMs) and the critical frameworks for Responsible AI.

---

### 📚 Learning Path Modules
This path is structured to move from core concepts to technical architecture and ethical implementation:

| Course / Module | Focus Area | Path |
| :--- | :--- | :--- |
| **Introduction to Generative AI** | Explaining GenAI, how it works, and how it differs from traditional ML. | [Folder](./Introduction%20to%20Generative%20AI) |
| **Introduction to LLMs** | Understanding Large Language Models, use cases, and prompt tuning. | [Folder](./Introduction%20to%20Large%20Language%20Models) |
| **Introduction to Responsible AI** | Google's AI principles and the importance of ethical AI development. | [Folder](./Introduction%20to%20Responsible%20AI) |

### 🧠 Technical Mindset
As an **AI Automation Engineer**, this theoretical foundation is vital for:
* **Model Selection:** Choosing the right LLM architecture for specific agentic tasks based on reasoning capabilities and token efficiency.
* **Responsible Automation:** Implementing verification gates and safety filters in n8n/Python workflows to prevent hallucinations and bias.
* **Advanced Prompting:** Understanding the underlying "Attention" mechanisms to write more effective, structurally sound prompts.
